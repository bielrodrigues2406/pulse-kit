# pulse-kit — notes for agents

- `pnpm typecheck` and `pnpm test` must pass before committing. Node 24, pnpm 12.
- TypeScript options mirror TriTracker's `tsconfig.base.json` (strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noPropertyAccessFromIndexSignature`). Do not relax them; TriTracker may consume these packages.
- `packages/*` are pure: no network, no file system, no DOM, no framework. I/O lives in `apps/mcp/src/adapters`.
- Names carry units (`rrMs`, `durationS`, `hrBpm`). Comments explain why, in English. User-facing text from the MCP tools is Brazilian Portuguese.
- Parsers throw `RangeError` on malformed input instead of guessing.
- Physiological outputs (alpha-1, VT1/VT2, respiration, cadence) are estimates and must be labelled so.
- The MCP server writes JSON-RPC only to stdout; diagnostics go to stderr. Health values never go to logs.
- No real recordings in this public repository. Test data is synthetic and seeded; real data lives in the private `physio-lab`.
- Changing `@pulse-kit/schemas`: run `pnpm --filter @pulse-kit/schemas build && pnpm --filter @pulse-kit/schemas json` and commit `packages/schemas/json`. The index fixture is generated by polar-drive-sync's own code; regenerate it there when the index format changes.
